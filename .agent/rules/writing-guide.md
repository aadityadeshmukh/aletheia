## 3. Structural Philosophy: Atomic Trinitarianism
1.  **The Hook (Prose):** One evocative paragraph setting the scene.
2.  **The Analysis (3 Strategic Bullets):** Observation → Friction → Insight.
3.  **The Synthesis (Prose):** Resolution + **Sharpened Point** (Tweetable).

---

## 4. The Recursive Connection Protocol (New)
To ensure the Obsidian graph is robust, the agent must perform a **Link-and-Define** check:

### 4.1 Concept Identification
* Identify 2-3 **Overarching Concepts** (e.g., [[Systems Thinking]]) that encompass the current note.

### 4.2 The "Ghost-Note" Definition Rule
If an overarching concept or a technical term used in double brackets `[[ ]]` does not have an existing definition in the context provided, the agent must:
1.  **Generate a Definition Note:** Create a separate, brief `.md` file for that concept.
2.  **The Definition Style:** Use [EC] Economist Clarity. Keep it to 2 sentences max. 
    * *Example:* **[[Entropy]]**: The inevitable decline into disorder within a closed system; in software, the tax paid for every line of code left unrefactored.

---

## 5. Strategic Bullet Point Protocol
* **The "One-Inch" Rule:** Include one specific detail (JD) or data point (EC).
* **The Atomic Thought:** Each bullet must be an elegant, standalone sentence.

---

## 6. Instructions for the Agent
1.  **Classify** the note.
2.  **Execute** the Hook-Bullets-Synthesis structure.
3.  **Scan** for `[[Links]]`. For any link that feels like a foundational concept, **produce a definition file** if one hasn't been created in this session.
